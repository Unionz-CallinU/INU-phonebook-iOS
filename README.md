# 인천대 전화번호부 앱 서비스
![Callinu](https://github.com/user-attachments/assets/4820e0b8-6924-44d9-9dbc-194220e9834b)

## 📎 Callin U

| 앱 소개 | Callin U는  인천대학교 학생들이 쉽고 빠르게 연락을 취할 수 있도록 도와주는 서비스입니다 |
| --- | --- |
| 개발 기간 | 2023.07.05 ~ 2023.10.05 |
| 개발 인원 | iOS(1), Android(1), Server(2), Designer(1) |
| 담당 역할 | iOS Developer |
| 사용 기술 | Swift , UIKit , Snapkit , CoreData |

## 담당 업무

- UIKit 및 Snapkit을 이용한 전체적인 화면 구현
- MVC 패턴사용하여 프로젝트 구성
- CoreData를 이용한 즐겨찾기 관련 CRUD 구현
- 연락처 조회를 위해 서버와 연동

## 주요 성과

- App Store에 출시하여 약 한달간 서비스
    - 인천대 홈페이지 리뉴얼 이슈로 서버 중단
- QA를 통해 앱 유지보수 진행
